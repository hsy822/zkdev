## What Does This Game Prove?

Players must cross a glass bridge by following a randomly generated correct path.

This "secret path" is generated in the browser and is stored as a private value called `secret_path`. Only its hash, called `public_inputs`, is publicly revealed.

As the user plays and creates a path (`user_path`), a ZK proof is generated to show the following:

```rust
use std::hash::poseidon2::Poseidon2::hash;

fn main(secret_path: [Field; 3], user_path: [Field; 3], public_hash: pub Field) {
    for i in 0..3 {
        assert(secret_path[i] == user_path[i]);
    }
    assert(hash(secret_path, 3) == public_hash);
}
```
This Noir circuit verifies two conditions:

1. The `user_path` matches the original `secret_path`.
2. The Poseidon2 hash of `secret_path` is equal to the provided `public_hash`.

---

## Key Points

- The server has **no knowledge of the correct answer**.  
  The `secret_path` exists **only in the user's browser**.

- Therefore, the verifier can only rely on the submitted **proof** and the **public inputs** to determine whether the player crossed successfully.

This is the essence of Zero-Knowledge Proofs:

> **"You don’t need to know the answer to verify that someone got it right!"**

## 4. If You Make It Across...

Once a player reaches the end, the following process is triggered:

- A ZK proof is generated that shows the Noir circuit has accepted the player’s solution.

```js
const { program } = await getCircuit();
const noir = new Noir(program);
const backend = new UltraHonkBackend(program.bytecode);

const noirInputs = {
  secret_path: secretPath.map(v => v.toString()),
  user_path: userPath.map(v => v.toString()),
  public_hash: publicHash.toString()
};

const { witness } = await noir.execute(noirInputs);
const { proof } = await backend.generateProof(witness);
```

This proof certifies that the player followed the correct path — without revealing it.

---

## How the Proof is Verified

The verifier does **not** know the correct path but can still confirm the proof is valid.

```js
const verified = await backend.verifyProof({ proof: proofBytes, publicInputs });
```

💡 If verification succeeds, it proves the player truly followed the correct path — **without revealing what it was**!
